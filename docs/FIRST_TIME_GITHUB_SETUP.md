# First-time GitHub setup

1. Create or use the public Project Cruise repository.
2. Copy the contents of this template to a feature branch.
3. Open a pull request and confirm `Public Boundary CI` passes.
4. In **Settings → Pages**, set **Source** to **GitHub Actions**.
5. Merge the pull request. `Deploy GitHub Pages` validates again, then deploys.
6. Protect `main`: require a pull request and the `validate-public-boundary` status check.

Do not upload the Phase archive or Private Release Support ZIP to the public repository.
