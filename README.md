# Project Cruise 候補最大化テスト版 v0.8

既存の275地点・152ルートを最大限にWebテストへ出す版です。

- 275地点をすべて `destinations.json` へ収録
- 152本の既存ルートを収録
- 275地点それぞれに「目的地直行」候補を自動追加
- 合計427通りの結果
- 同じ最終目的地は、選択中の時間枠を一巡するまで原則再表示しない
- 最終目的地単位で均等抽選し、特定地点への偏りを抑制
- 条件付き・未実走候補も含むため、出発前確認が必須

## 時間別候補

- 90分：112種類の最終目的地／144通り
- 2時間：139種類の最終目的地／208通り
- 半日：265種類の最終目的地／427通り

# Project Cruise GitHub Pages Prototype

大田区・蒲田周辺を起点にした「近くて濃い」ドライブ候補検索の静的プロトタイプです。

## データ
- 近距離コア地点: 93件
- 用途別近距離ルート: 45件
- 合法な路上短時間アクセス: 10件
- Excel正本: `Project_Cruise_合法路上駐車統合版.xlsx`

## GitHub Pages公開手順
1. ZIPを展開
2. 展開した中身をGitHubリポジトリ直下へアップロード
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / Folder: /(root)
6. Save

公開URL例:
`https://zou400.github.io/project-cruise/`

## 注意
`index.html`をPCで直接開くとJSONを読み込めない場合があります。GitHub Pages上では動作します。


## UI 0.3
一覧表示を廃止し、時間選択→ルートガチャ→Googleマップ起動の単一導線に変更。

## UI 0.4
- 行先カードとルート地図を同時表示
- OpenStreetMap + Leafletによるルートプレビュー
- 出発・経由地・目的地を色分け
- OSRMで道路ルートを取得し、線をアニメーション表示
- 地図クリックでGoogleマップへ移動
- スマホではカード→地図の縦並び
- 外部地図取得に失敗してもGoogleマップリンクは利用可能

## UI 0.5
- スタート地点を「現在地」または登録済み起点から即時選択
- 現在地取得失敗時は登録済み起点へ自動フォールバック
- 起点変更時に地図・GoogleマップURLを即時再生成
- 登録済み起点は `data/config.json` だけで変更可能

### 登録済み起点の変更
`data/config.json` の以下3項目を変更してください。

- `name`: 画面に表示する名称
- `query`: Googleマップ検索用の名称または住所
- `coordinates`: `[緯度, 経度]`

## UI 0.6 / Route policy
- 時間選択を「総所要時間」から「移動に使える時間」へ変更
- 各地点の標準滞在は20分
- 1地点の滞在上限は25分
- 大規模公園・展望施設でも長時間滞在を前提にしない
- 既存の長い滞在時間は `originalDwellText` に保存し、ガチャ判定には使用しない
- 方針値は `data/config.json` の `routePolicy` で変更可能
