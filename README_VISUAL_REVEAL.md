# Project Cruise v0.10.2.1 Visual Reveal

GitHub-ready integration package based on the v0.10.0 canonical release.

## Included

- Canonical destination and route data
- Context Engine, re-roll, device-local learning, departure and return feedback
- Cinematic `MISSION UNLOCKED` destination reveal
- Local visual fallbacks for airport, waterfront/bridge, industrial night, and urban architecture
- Long destination-title handling
- Mobile-first reveal and departure action
- Dark world-map treatment named `CRUISE ATLAS`
- Google Maps departure links
